## 6. 平台配置含义

若 `complete_plata` 同时服务两校：

1. 租户、目录、学分规则、审核角色全部隔离。
2. 无锡学院打开：立项、实验班、学分、毕设替代互斥校验。
3. 无锡太湖学院打开：认定一览表、竞赛月活动、教务 / 创业学院 / 团委三角色会签。
4. 报表按学校分别导出，不得合并计算级别。
