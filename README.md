# complete_plata · 竞赛平台

本仓库收录面向 **无锡学院**、**无锡太湖学院** 的大学生学科竞赛与创新创业竞赛执行材料，供教务/双创部门、二级学院、指导教师和信息化平台协同使用。

## 使用原则

1. **政策以学校最新正式文件为准。** 手册把公开通知里的流程写成可执行步骤，不替代红头文件。
2. **两校分轨、同一闭环。** 立项 → 培育 → 院赛/校赛 → 省赛/国赛 → 认定奖励 → 归档复盘，节点名称不同，闭环相同。
3. **目录动态更新。** 无锡学院竞赛定级随《全国普通高校大学生竞赛分析报告》调整；无锡太湖学院以当年《学科竞赛认定一览表》为准。

## 编制说明

任务提出时要求“根据这份文件”编写。仓库与对话中未附带来源附件，因此本手册依据两校官网已公开的管理办法、立项通知、校赛通知和认定目录整理，并在主手册文末列出依据清单。若后续补交内部文件，应优先按内部文件修订对应章节。
