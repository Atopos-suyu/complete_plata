本网页把两校已公开的管理办法、立项与校赛通知、认定目录和学分政策展开为分章页面。政策以学校最新红头文件为准，手册不替代正式制度，也不估算未公开的奖金金额。

一句话原则

目录内竞赛才资助，院赛筛质量，校赛定省赛名单，证书落款时间定级别，材料不实即取消资格。

两校分轨、同一闭环：立项 → 培育 → 院赛/校赛 → 省赛/国赛 → 认定奖励 → 归档复盘。

第 0 章

怎么用这份手册

按角色取用章节，不要整本从头读到尾。动手前先看两校对照，避免把无锡学院的系统、文号和学分规则套到太湖学院。

校级部门

看组织、立项经费、教师考核、学期十问。用来排年度计划、发通知、审立项、拨经费、做认定。

二级学院

看闭环、培育、院赛 SOP、合规审查。落实“一把手”责任、选拔、材料闸门和指标完成。

指导教师 / 团队

看重点赛事 SOP 和学生激励。准备作品、报名、答辩、截图归档。

平台运营

看系统与归档。两校租户隔离，目录、学分规则、审核流不得混用。

阅读顺序建议：首页选学校 → 组织与职责 → 年度日历 → 对应 SOP → 打开执行清单边做边勾。

第 1 章

工作目标、范围与竞赛分级

执行任何赛事之前，先完成定级。不定级就不能报经费、不能认定学分、不能对外宣传奖项级别。

目标无锡学院无锡太湖学院
育人以赛促教、促学、促创；Ⅰ类（国创大赛、挑战杯）引领以赛促学、促教、促用；教务学科赛 + 创业学院创业赛 + 团委挑战杯
质量对接权威赛事，去伪存精；未立项原则上不资助以当年认定一览表为边界
覆盖班级双创委员；省级及以上大创必须报国创大赛学科竞赛月集中发动；大创按学院排序推荐

适用范围

  • 覆盖：学生学科竞赛、创新创业竞赛、校内选拔、实验班/工作室、实践创新（双创）学分、获奖奖励、学院考核。
  • 不覆盖：教师教学竞赛（微课、教学创新赛）。教师赛走教师发展/教务教学竞赛口，不走学生竞赛经费与学分。
  • 对象：全日制本科生为主。无锡学院国创大赛允许毕业五年内校友任负责人（以当年校赛通知为准）。

第 3 章

年度工作闭环

两校节点名称不同，闭环相同。详细月份见年度日历。

1. 目录
更新认定目录 / 一览表，传达到指导教师。
2. 立项
承办单位 + 指导教师申报，学校审定后下达经费与任务。
3. 培育
实验班、工作室、大创、学科竞赛月、校队集训。
4. 院赛
审核 + 公示 + 推荐。质量闸门在学院，不在学校临时补材料。
5. 校赛
网评 / 路演 / 答辩，公示省赛名单。
6. 官方网报
国创网、挑战杯网或各赛主办方系统。截图当场归档。
7. 省赛国赛
差旅、器材、模拟答辩、现场保障。
8. 认定
学分、奖金、职称积分，证书落款日期决定年度。
9. 复盘
归档数据成为下一年度立项依据。
硬性约束（无锡学院已发文，太湖学院建议同等执行）：立项结束后未申报项目原则上当年不再资助；已立项必须执行，擅自停赛收回经费并取消承办资格；推荐校赛/省赛必须先院内公示；官方报名截图、证书、作品不得事后补造。

资格要点

  • 负责人：在校本科生或毕业五年内校友（2021 年及以后，以当年通知为准）。
  • 团队 3–15 人，须为实际成员；鼓励跨学院、跨学校、留学生。
  • 归属以负责人所在学院为准，学院唯一；除产业命题教师外年龄不超过 35 周岁。
  • 国家级、省级大创立项团队必须报名，截图作为结题必要条件。
  • 赛道：高教主赛道、青年红色筑梦之旅、产业赛道；一项目只选一个赛道。

直通校赛决赛（仍须审查和公示）

权威期刊论文或已授权发明专利；高层次人才及曾获 Ⅰ 类国奖教师作为第一指导教师的项目；校友项目。

严禁改标题批量上传、全盘抄袭往届、从其他比赛不改写即报。学院对科技成果、知识产权、财务、运营、荣誉的真实性负全部责任。

第 6 章

项目挖掘与培育

无锡学院十条渠道

学院竞赛负责人每学期对照一次，缺项在专题会上说明。

  1. 省部级及国家级重大/重点科研成果转化（科技处）。
  2. 年薪制教师须以第一指导教师身份指导 Ⅰ 类竞赛，特殊情况报主管校领导。
  3. 校企产学研项目。
  4. 省级及以上大创必须转报国创大赛。
  5. 国家大学科技园在园项目。
  6. 毕业五年内创业校友，每年至少 1 个优秀校友企业参赛。
  7. 校院两级双创工作室：每年培育 2–3 个项目；完不成则减资或迁出。
  8. 创新创业教育实验班：优先 Ⅰ、Ⅱ 类；课程必须录入教务系统并接受督导，否则不计工作量。
  9. 创业种子计划 / 精英培训班：科技创新 + 创业运营双导师；SYB、GYB。
  10. 周周有讲座、月月有活动；宣讲进学院；社团承接。
太湖学院四条主线
  1. 大创计划形成国家级（推荐）、省级、校级梯队，优秀项目转入国创或挑战杯。
  2. 创业学院：创客空间、孵化器、创业讲坛、企业命题。
  3. 学院学科竞赛办：固定导师、赛种、校队，避免通知来了再找人。
  4. 学科竞赛月把分散赛种收成一次全校动员，再转入日常训练。
实验班/集训班最低要求：大纲、课表、考勤、过程作品、结业名单。太湖学院若以第二课堂或社团开班，至少由承办学院备案。结业建议以赛代考。

第 7 章

院赛审查与合规

二级学院是质量闸门。校级部门抽查，不代替学院审查。

资格

学籍、年级、在校或校友年限；人数与分工；是否实际成员；是否重复报同一赛道；产业赛道教师身份。

内容与知识产权

真实健康合法；专利数据品牌权属清晰；财务运营荣誉可追溯；伦理手续齐全；禁止抄袭、代做、买卖、假合同。

处理

违法或违背大赛精神：立即取消资格和奖项。学院漏审的，考核扣减并倒查指导教师。

第 13–15 章

学期十问、依据与修订

1. 本学期目录 / 一览表是否已传达到指导教师？

未传达不得启动报名动员。

2. 立项是否覆盖拟参赛项目？

未立项是否已告知“不资助”。

3. Ⅰ类 / 重点赛种是否有名单、导师、节点？

没有名单等于没有工作。

4. 大创项目是否全部完成国创网报名？（无锡学院）

报名截图是结题必要条件。

5. 院赛公示和审查表是否齐全？

无公示不报校赛。

6. 官方报名截图是否已归档？

不得事后补造。

7. 学分 / 奖励申报是否在窗口期内？

毕业审核前一周再报，往往录不进系统。

8. 实验班是否入教务系统？（无锡学院）

不入库不计工作量。

9. 经费是否按批复科目使用？

申报数不是批复数。

10. 上一届复盘里的问题本学期改了没有？

复盘不改，等于没复盘。
